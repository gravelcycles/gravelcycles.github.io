Eurail Map Uploader

A desktop tool for uploading reviewed railway map exports to Google Drive and managing project files at the account owner's direction.

The uploader stages KML files in Drive for selection in Google My Maps. Related owner-operated helpers support project-file access and backups. The application is currently operated for the developer's own Google account.

How it works

  1. Start the desktop tool and authorize access through Google's sign-in page.
  2. The tool uploads or updates the selected map files and checks the returned file checksums.
  3. Open Google My Maps separately and import the staged files into the intended map.

Uploading a file to Drive does not import a My Maps layer or change its sharing settings.

Google permissions

The map uploader requests drive.file to create and manage files created by or explicitly opened with the app. A separate owner-authorized helper requests drive for full Drive file access needed for the owner's file-management and backup tasks. The tool checks the signed-in account before saving credentials.

Authorization runs from the desktop tool. This informational website does not ask you to enter a Google password or upload credentials. Read the privacy policy for data access, storage, sharing and deletion details.
