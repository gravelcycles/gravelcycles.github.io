Privacy policy

This policy covers Eurail Map Uploader and its related owner-operated Google Drive helpers. The developer and privacy contact is eurailmaxxer@gmail.com. The application is a personal tool currently operated for the developer's own account.

Data we access

The application uses Google OAuth to obtain permission to access Google Drive. It checks the signed-in account's email address to confirm the intended owner. It receives OAuth access and refresh credentials, and processes file names, identifiers, folder relationships, checksums and other metadata needed for the requested operations.

The map uploader uses https://www.googleapis.com/auth/drive.file to create and manage files created by or explicitly opened with the app. The separate full-Drive helper uses https://www.googleapis.com/auth/drive, which permits access to all Drive files within the signed-in account's permissions. That grant can support listing, reading, downloading, creating, updating, organizing or deleting files when the owner requests those tasks.

How data is used

Data is used to authenticate the intended account, stage map exports, check uploads, maintain project backups, and carry out file-management tasks requested by the owner, including through owner-authorized automation or assistants. Credentials are used to call Google APIs and renew access. The application does not collect Google passwords.

Storage and security

Credentials are retained in private files on the owner's computer or in private secret settings or credential files in an owner-approved execution environment. Local credential files written by the helpers use owner-only permissions. Google API requests use HTTPS. Downloaded project files and backups may remain on the owner's computer or in owner-approved cloud storage. Upload records may retain file identifiers, hashes and operation results.

The owner may deliberately provision credentials to a private cloud runtime or an authorized assistant to perform requested work. The public website and public source repositories do not receive or contain those credentials. Credentials should not be posted in public pages, repositories or ordinary chat messages.

Sharing and limited use

Google processes authentication requests and Drive file operations. Owner-approved hosting, storage or assistant providers may process the credentials or file data necessary for tasks the owner authorizes. Files are shared or published only at the owner's direction; the map uploader itself does not change Drive sharing permissions.

Google user data is not sold, provided to data brokers, used for advertising, or used to develop, improve or train generalized artificial intelligence or machine-learning models. Access to and use of Google user data is limited to the application's disclosed, owner-directed functionality.

Eurail Map Uploader's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Retention, revocation and deletion

Credentials and operational records are retained while needed for the owner's requested workflow, until the owner removes them or requests deletion. Downloaded files and backups remain until the owner deletes the retained copies. There is no automatic deletion schedule.

You can revoke the application's Google access at Google Account connections. Revocation prevents further authorized API access but does not delete files already uploaded to Drive or copies already downloaded. To remove those, delete the relevant Drive files, local files and backups, and remove credential copies from every execution environment or secret store where you placed them.

For access or deletion help, contact eurailmaxxer@gmail.com. A deletion request covers retained data under the developer's control; copies independently retained by the account owner must also be removed by that owner.
